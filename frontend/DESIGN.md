## 一、材质宪法

这块布上只有四种东西，每个组件必须属于其中一种，不得混用配方。

| 材质 | 配方 | 用在 |
|---|---|---|
| 布 | `--base` 加光层 | 画布底色。她的话用最轻一档玻璃（`--glass-fill-quiet`），比你的气泡淡一档，但看得见 |
| 纸 | 不透明、暖、`--r-paper`、0.5px `--line` 描边、**没有投影** | 贴纸、日历、格纸、冷屏的表单与按钮、条款纸、需要帮助纸、订阅席位卡、她的档案纸、阶段卡 |
| 玻璃 | `backdrop-filter: var(--glass-blur)`、填充 `--glass-fill`、0.5px `--glass-edge` 边、`inset 0 1px 0 --glass-hilite` 顶光。**禁止 box-shadow**：玻璃靠边缘的光浮起来，不靠影子 | 凡是浮在布上、不是物件的东西：顶栏三件、输入胶囊与两颗圆键、你的气泡、雾层上的卡、长按菜单、附件面板、toast、零件匣的行、事件卡、登录框、二级页动作键 |
| 机器 | `--machine` 实色、`--r-widget` | 唱机、游戏机、闹钟 |
| 她的形 | 墨。身后是光，动作背后有一层落后 180ms 的残影 | 幽灵、头像、笔尖 |

例外条款（都写在 CSS 注释里，不算违宪）：

- 唱片紫 `#9A86D6`、贴纸五色、天空渐变、楷体 27px——物件自己的颜色，不随主题，不进 token。
- `.msg.you` 的 blur 降到 12px：消息列表同时压着几十条气泡，每条 18px 太贵。
- 字标字距 `.42em` / `.32em`：字标专用，不进 `--ls` 两档。

「即将开放」克制态（壳清单原则）：冷屏纸（`.helpdoc`）、一行说明、一个返回，没有插图没有多余按钮。

## 三、光系统（warmth）

关系的全部长期状态压成一个 0–1 标量 `warmth`（`body.dataset.warmth`，未设取 .7）。

- 五团光分两组：暖团（桃 0、琥珀 2、玫瑰 4）随关系亮暗；冷团（丁香 1、天青 3）几乎不动。冷下来不是光消失，是暖色先走，屋子剩蓝紫余光。
- 夜间不换暗色光：同一组光色，少一些、收窄一些（`poolsDark`），光与光之间留出真正的暗。
- A/B 两套 `<i>` 组交叉淡化（光的 background 不能过渡）：默认 4s，结束 1.6s。`--w` 不能过渡，用 rAF 推；布色与漂移速度吃 `--w`。
- 光分三层各自漂移（96s/128s/160s），时长乘 `(2 - --w)`：关系冷下来光几乎不动。
- 热到顶（w ≥ .9，body.hot）多一层极大极淡的琥珀，只进不出。
- 疏远（w ≤ .25，body.distant）：光由 `poolGain` 收敛，她的头像去饱和。
- 她在打字（body.hertyping）：她那侧第一层光抬一点（brightness 1.06）。
- 顶栏小字随段位：在线 / 刚刚在线 / 三小时前在线 / 离线 / 空（结束）；断网（模拟）时优先显示「连不上」。

## 四、她的行为规则

她的三个化身是一连的：幽灵是她没成形时的样子，头像是她，笔尖是她从头像里伸出来的手。

### 幽灵（注册全程陪同）

- 在第 6 屏凝形：屋子光被抽走（body.gathering）再回来；她从模糊聚成形（condense 1240ms），眼睛最后睁（1240/1300ms）。
- 按「继续」她一跳（hop 420ms），**飘**去下一屏（transform 720ms），不是消失重现。
- 冷屏里她缩小坐在进度条尽头（`.perch`，36/104 档），三层轮廓光收掉——她是冷屋子里唯一暖的东西。
- 眼睛：跳视有节奏（900–2600ms 随机），抬眼看你 / 看门（CTA）/ 乱看三种；眨眼与跳视错开（忙时不眨）。点屏幕任意处她盯过去 1s 回；点她是 poke（挤压弹起+眨眼+震动，地面光涨一下）；按住她闭眼，松开睁开，滑出去松开不卡闭眼。
- 冷屏停太久（8s）：她看空着的框再看你，不催。
- 进入页：飘回中央、光回来、静静看你，3.2s 化成墨圆；落地那帧头像出现、胶囊弹一下，无空圆、无大小跳变（锚点不缩放，墨圆保持 30px）。
- 她现在不散：没有 leaving，她跟着走；回到开始页/登录页她才不在。

### 引导（只在第一次进画布）

不用文字讲规则，她做一遍：从头像探出 → 带你看布、物件（把唱机带进来，等你拖，6s 没动她自己继续）、气泡、输入，再回去。约 11 秒。点任意处跳过。calm（减动效）时她不出来，四行字打完即结束。记 `after-guided`。
引导期间 abar、剧本播放器、arrive 全部挂起（guiding）。

### 笔尖（她的手）

- 手只在做事时出现：放东西（place）、写字（ink）、指一下（point）。没有第四件事——随机漂移与「搬回原位」都删了；你挪过的东西留在你放的地方。
- 所有动作起点与终点都是她的头像圆心；出手那一刻头像轻轻 press 一下。
- 一次动作是一条预先规划好的轨迹（三次贝塞尔 + 随机弓形），规划完按时间播完，中途不重新决定。时长按 Fitts（对数），速度遵守三分之二次幂定律（曲率越大越慢）。拖尾是笔尖扫出的带（Catmull-Rom 加密、轴对齐椭圆法线支撑、共用边无接缝），每帧重画，走过不留。
- 扁头笔：笔尖横宽纵窄（3.2 : 1.33，2.4 比 1），点不出正圆。
- `warmth < .45` 她不出手（只说话）；`< .25` 连笔也不拿（没有 ink）。结束时手不再出现。

### 她说话

正在输入 → 停留（时长看字数，`warmth<.45` 时 ×2）→ 话到达。你连发，她重新想：正在输入不叠加，回复不叠加。已读只挂你最新一条，她一回复就撤。
她的话到达才进场（每次进屏重放 rise）。

## 五、屏与过渡

- 屏：开始 5 / 注册第一步 6（她出现）/ 出生日期 0 / 三点说明 1 / 为什么 8 / 从哪知道 9 / 关于你 11 / 登录 7 / 进入页 10 / 画布 4 / 画画 3 / 零件匣 12 / 独件页 13 / 结束页 14。暖屏 `WARM=[3,4,5,6,7,10,12,13,14]`，冷屏只有表单五步 `FORM=[0,1,8,9,11]`。返回表 `BACK`。
- 冷屏进出有方向：前进右滑入，返回左滑回（body.going-back）；暖屏之间保持溶解。
- 进入页 → 画布：进入页慢一档淡出（600ms），墨圆飞 720ms，落地同帧交接。
- 玻璃感交互（设置/成就/她的档案纸/权限共用 openG/closeG）：原页面自己糊开（`body.glassed` 的 filter: blur 18px，任何引擎都渲得出），白雾与内容随后淡入浮起；关闭反过来，走完才摘覆盖层。
- 抽屉/阶段卡的雾同一条（380ms）。
- 键盘：visualViewport 收起 #app 高度，输入区一直露在键盘上方。
- `?slow=N` 慢放 N 倍复查过渡（SC）；减动效（prefers-reduced-motion）时 SC=0.06，她的时间点同比例压缩，最终状态完整。

## 七、Widget 与画布

- 画布（data-s=4）初始为空：widget 与气泡都靠 `placeWidget/herSay/youSay` 一个个放进来。widget 模板集中在 `<template id="wtpl">`，登记表 `WIDGETS`（模板、尺寸、init、make）；新 widget 只加一条登记与一个 init。
- 七件：唱机（点唱针抬落）、天气（点换她/你重点）、日历（点日子画圈只一个，她的红记号动不了）、贴纸（点换纸色）、游戏机（摇杆接手贪吃蛇，不劫持页面滚动）、猜词格纸（楷体、点空格翻字）、闹钟（上下搓调时间、向下是加、右缘 AM/PM、今天/明天/每天）。
- 段式屏与点阵屏的熄灭段/点都画出来——这是屏最像屏的地方。段式屏显示不了汉字，中文是印在玻璃上的固定字样。
- 你挪过的东西留在你放的地方（slot 只在落下那刻定位，拖动后 clamp 在布内）。
- widget 消隐：雾把 widget 托起来，气泡按到 widget 的距离变淡（130px 内渐变，地板 0.30）。
- 零件匣只装她真的给过的东西（画布上放过的种类）；空匣一行「她还没给你东西。」。独件页一件一物，副本与原件吃同一套交互（机器类各自实例）。
- 机器实例进第 4 屏 start、离屏 stop；清画布随 DOM 退役。

### 她给的挂件（成就页）

- 成就页是一串 3D 挂件，一页一枚、左右滑动翻看：`frontend/charms.js`（three.js，`vendor/three-bundle.js`，esbuild 一次性打包产物入库、不走 CDN）在首次打开/首次解锁时动态 import，主画布零开销。五枚全是程序化几何（1 单位 = 1cm，尺寸与 Blender/打样共用）：凋谢的玫瑰（她第一次拒绝）、信封（她第一次主动发消息）、蛋形小游戏机（她第一次放 widget 且你碰了它）、火柴盒（第三天）、戒指（第七天，直接套在开口环上不加链）。
- 每页：页顶中央一个开口环垂下来（环 + 珠链 + 挂件）；空页只有一个开口环，环下什么都没有，没有字。底部常驻纸条显示当前页的「M月D日 · 第 N 天 · 她那句话」（文字在页面上，不在物件上），圆点五个：当前页 `.on`，已解锁实心、未解锁空心。首次打开停最新解锁的那一枚，全空停第一页。
- 翻页手势：横向拖动 >10px 跟手，松手按速度（>.35 px/ms）或位移（>屏宽 30%）翻页，否则弹回；`mobile.position.x` 弹簧追页。点一下（<7px 且 <450ms）当前页荡起来（buzz(5)）。待机微摆只跑当前页与邻页；手机倾斜整页顺重力偏（iOS 要系统授权弹窗，本版不请求不启用）。
- 她给的过程：离屏 renderer 把该挂件（含小环、不含链）渲成 512×512 透明 PNG（每枚只渲一次，存 `after-charm-img-*`）→ 笔尖把它当 charm widget 放到画布 → 晃两下 → 她说一句 → 4s 后 PNG 飘进右上角圆键（FLIP），圆键图标从此是小开口环，新到一枚带红点，打开成就页即消失。首次打开时新到的那枚多晃一次。
- 降级（无 WebGL2 / 减动效 / `?flat=1` / 8 帧平均 >24ms）：同一套翻页平铺平涂 PNG（`.pgr` scroll-snap + flatPNG 2D 绘制），CSS 摆动保留，滚动同步圆点与纸条。`?charms=all` 或演示菜单「五枚都有」直接给齐（`charmsGrantAll()`，不走仪式）；「清空挂件」回新用户态；`?fx=1` 桌面后期（GTAO+景深）。
- 解锁钩子：say 带 `refuse:true` 或 warmth 首次 ≥.6→≤.45（玫瑰）· `arriveAct` 首次（信封，不含 hello）· 首个 widget 上首次 pointerup（蛋机）· 剧本 `day`≥3 / ≥7（火柴盒/戒指，幕首她先给挂件再说正事）；真实模式按 `after-met` 自然日，hello 后补发。
- 环境贴图按 renderer 各建各的（WeakMap，快照 renderer 用完连贴图一起还）；GL 场景只建一次，重开只挂新解锁、摘掉清空、亮暗调灯；`resize/orientationchange` 重取景。

## 八、剧本播放器与状态

- 剧本《十二天》七幕在内嵌 JSON（字段见 `SCRIPT.md`）。动作：say / you / place / ink / card（decide/coop）/ recall / warmth / presence / wait / arrive / stage / branch / end。`?scene=N` 从第 N 幕起播；`pace()` 让剧本吃 SC。
- 翻旧账：recall 引用 decide 记下的 stamp（`player.marks`），旧消息旁 stamp 亮一下，滚过去 400ms 再滚回。
- 分岔（第六幕）：播放器停在 branch，演示菜单选「回/不回」；回 → warmth 回 .6 且和好（第十二天不来）。`skipIfMuted` 的幕在「停止她的主动联系」开着时整幕跳过。

## 九、字串（STRINGS）

界面字串集中在主 script 顶部的 `STRINGS` 对象（只抽，不翻译），三种声音各守各的规则：

| 声音 | 出现在 | 规则 |
|---|---|---|
| 平台 | 冷屏、设置、条款、需要帮助、权限 | 短句，不用「亲」「哦」，不用感叹号；称「你」；说「平台」不说「我们」（条款除外） |
| 她 | 画布上的话、事件卡、贴纸、阶段卡结束语 | 克制；不解释、不道歉、不劝 |
| 系统 | 空态、提示行、toast、错误 | 一句话，句号结尾，不超过 14 字 |

- 静态 HTML 由 `STR_BIND`（选择器 → 路径，模式 text/ph/first/last/mid）在启动时 `applyStrings()` 一次写回；绑定落空会 console.warn。
- JS 动态字串直接引用 STRINGS。
- 剧本 JSON、widget 登记表（name/desc/hint）、演示菜单标签是内容或脚手架，不进 STRINGS；aria-label 留在 HTML。
